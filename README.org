A WebKit browser for Emacs built with xwidgets: tabs, history and bookmarks, Vimium-style
keyboard hints, a proxy, and, on macOS, Chrome extensions, wallets such as Rabby among them.  It
also keeps Emacs on macOS from the crashes that closing pages and running their scripts could
cause.  In code, the package and prefix are ~lispm-browser~.

* The LispM projects

| [[https://github.com/LispMachineLab/lispm-agent][lispm-agent]]     | AI agents inside Emacs                                            |
| [[https://github.com/LispMachineLab/lispm-desktop][lispm-desktop]]   | Emacs as a Mac OS 9 desktop, set up as a workspace for agents     |
| *lispm-browser* | a WebKit browser in Emacs, with keyboard hints and Chrome extensions (this repository) |
| [[https://github.com/LispMachineLab/lispm-store][lispm-store]]     | the catalog LispM Desktop's App Store installs from               |

The browser needs neither of the others.  LispM Desktop draws it as Netscape Communicator's window.

* Installation

Emacs 30.1 or later built with xwidgets (on macOS the NS build; elsewhere GTK with WebKitGTK).
Chrome extensions need macOS 15.4+ and Swift (Xcode or its command line tools), which builds
their module the first time one is added.

#+begin_src emacs-lisp
(use-package lispm-browser
  :vc (:url "https://github.com/LispMachineLab/lispm-browser" :rev :newest)
  :config (lispm-browser-setup))
#+end_src

=M-x lispm-browser= shows the browser, at ~lispm-browser-home-url~ when no tab is open, and
=M-x lispm-browser-browse-url= opens an address.  Set ~browse-url-browser-function~ to
~lispm-browser-browse-url~ to open links from everywhere in it.

* Features

- *Tabs*: every page is a tab with its page's icon and a close button, in a tab line; a middle click
  closes a tab too.  Closing the shown tab shows its neighbour, closing the last one quits.
- *History and bookmarks*: pages visited go to ~lispm-browser-history-file~; bookmarks are
  Emacs's own (=bookmark.el=), so =bookmark-jump= opens them too.  =C-l= completes addresses
  from both and searches for anything else (~lispm-browser-search-url~).
- *Keyboard hints*, as Vimium's: =f= labels the links, buttons and fields in sight, and typing a
  label follows it.  In a field Emacs's keys edit, =RET= submits and =ESC= leaves.
- *Chrome extensions*, on macOS 15.4+, run by WebKit itself (WKWebExtension) through a Swift
  module: toolbar buttons with badges and popups, an Extensions menu, a management page at
  =lispm://extensions=, and Add to LispM on Chrome Web Store pages, which checks the signature
  and asks about permissions first.  Shims for Chrome APIs WebKit lacks let heavy extensions
  such as Rabby run.  Extensions get no bookmarks, history, downloads or native messaging.  Set
  =LISPM_BROWSER_WEBEXT_VERBOSE= to see their console errors.
- *No crashes on closing pages*: in Emacs 31's NS build, closed pages' xwidgets and pending
  script callbacks are kept from the garbage collector until WebKit is done with them
  (~lispm-browser-run-script~).
- *A proxy* for the pages, which url.el's settings and =http_proxy= do not reach:
  ~(lispm-browser-set-proxy "socks5://127.0.0.1:7890")~, with ~lispm-browser-proxy-exceptions~.

The extension module is mostly ported from [[https://github.com/driceroland/Search][Search]], a WebKit browser for macOS.

* Keys

Command keys, as a Mac's browsers have them, where Command is Meta:

| =C-l=, =M-l=               | open an address, or search                              |
| =M-[=, =M-]=, =M-r=, =M-.= | back, forward, reload, stop                             |
| =M-t=, =M-}=, =M-{=        | a new tab, the next, the previous                       |
| =M-d=, =M-b=, =M-y=        | bookmark the page, open a bookmark, open a page visited |
| =f=, =F=, =i=              | follow a hint, in a new tab; go to the first field      |
| =M-e=                      | press an extension's button                             |

~(lispm-browser-setup 'none)~ binds none of them; ~lispm-browser-keys~ lists them.  Each
extension action is also a command: ~lispm-browser-extensions-install~, ~lispm-browser-extensions-load-unpacked~,
~lispm-browser-extensions-pin~, ~lispm-browser-extensions-list~, ...

* A look of its own

By default the browser draws only a tab line.  A program can draw it otherwise, as LispM Desktop
draws Netscape Communicator, through these:

| ~lispm-browser-window-function~            | the window showing the page                         |
| ~lispm-browser-tab-window-function~        | where a new tab opens when no window shows one      |
| ~lispm-browser-show-function~              | showing the browser                                 |
| ~lispm-browser-raise-function~             | bringing it in front once it shows a page           |
| ~lispm-browser-tab-hook~                   | each new tab's buffer: its tab, header and mode lines |
| ~lispm-browser-change-hook~                | the page or the tab shown changed                   |
| ~lispm-browser-redraw-hook~                | a title or a page icon changed                      |
| ~lispm-browser-before-quit-hook~           | the browser quits, its tabs still open              |
| ~lispm-browser-quit-hook~                  | the browser quit, its tabs closed                   |
| ~lispm-browser-places-changed-hook~        | the history or the bookmarks changed                |
| ~lispm-browser-tab-line-end-function~      | what the tab line ends with: the extensions' buttons |
| ~lispm-browser-extensions-anchor-function~ | where an extension's button is, for its popup       |
| ~lispm-browser-extensions-changed-hook~    | an extension's button, badge or pin changed         |

It draws with ~lispm-browser-tabs~, ~lispm-browser-shown-buffer~, ~lispm-browser-uri~,
~lispm-browser-title~, ~lispm-browser-favicon~, ~lispm-browser-navigation-state~,
~lispm-browser-history~ and ~lispm-browser-bookmarks~; for extensions,
~lispm-browser-extensions-buttons~, ~lispm-browser-extensions-menu-items~ and
~lispm-browser-extensions-button-menu-items~.  A button drawn with the text property
~lispm-browser-extensions-button~ is located by ~lispm-browser-extensions-button-anchor~ or, from
a click, ~lispm-browser-extensions-event-anchor~; ~lispm-browser-extensions-press~ hangs the popup
there.

extension module's tests, on a Mac.
